# Разработка голосом внутри VR — дизайн первой версии

Дата: 2026-11-16

## Зачем

Работает только левый контроллер Quest 3S. Нужен полный цикл
разработки, не выходя из VR: зажал курок → сказал «добавь пистолет» → отпустил →
пистолет появился в сцене. Перед глазами — окно с сессией Claude.

## Цели

- Голосовой промпт по курку левого контроллера, распознавание — встроенной диктовкой
  Claude Code (не Whisper: качество не устраивает).
- Правки сцены применяются без перезагрузки страницы и без выхода из VR.
- В VR видно настоящую сессию Claude Code: что распозналось, что Claude делает, что отвечает.
- Всё штатное управление — одной левой рукой.

## Не цели (первая версия)

- Красивый собственный чат вместо терминала.
- Снимки из шлема, чтобы Claude «видел» сцену.
- Работа вне домашней Wi‑Fi сети, несколько пользователей.

## Чего быть не должно

- Сценариев, где в штатной работе надо снять шлем или тянуться к правому контроллеру.
- Перезагрузки страницы при обычной правке сцены.
- Испорченных настроек звука: микрофон по умолчанию обязан возвращаться на место,
  в том числе после падения сервера.

## Ограничения (проверено)

- Перезагрузка страницы завершает VR-сеанс → основной механизм — подмена кода сцены на лету.
- WebXR и микрофон в браузере Quest работают только по HTTPS.
- Встроенная диктовка Claude Code пишет только с микрофона Windows «по умолчанию»,
  открывает его в момент начала записи, требует вход через claude.ai (есть), язык — Russian (уже выставлен).
- Удержание пробела определяется по автоповтору клавиши: достаточно слать пробел ~30 раз в секунду.
  Проверено: `listening…` появляется через ~0,3 с, живой текст виден во время речи,
  после «отпускания» текст остаётся в строке ввода и сам не отправляется.
- Виртуальный микрофон уже есть: «Speakers (Steam Streaming Microphone)» →
  «Microphone (Steam Streaming Microphone)». Особенности драйвера: копирует байты как есть,
  поэтому играть надо в монопольном режиме WASAPI, 48 кГц, 2 канала, 32 бита;
  добавляет ровно +30 дБ (компенсируем −30 дБ); микрофон бывает в режиме «без звука» (снимаем при старте).
- `python` в PATH — чужое окружение (hermes). Проекту нужен свой venv на Python 3.12.

## Рассмотренные подходы

- **A. Один настоящий Claude Code в псевдотерминале (выбран).** Одна и та же сессия и
  распознаёт речь, и выполняет работу, и показывается в VR. Меньше всего частей; текст виден
  прямо во время речи; работают все возможности Claude Code. Минус: в VR это терминал, а не чат.
- **B. Скрытый Claude Code только как распознаватель + отдельная сессия через Agent SDK**
  (исходная идея пользователя, текст перехватывается hook'ом `UserPromptSubmit`).
  Даёт собственную панель и кнопки разрешений, но вдвое больше частей и точек отказа.
  К нему можно вернуться, если терминал в VR окажется неудобным.
- **C. Локальный Whisper.** Отклонён пользователем.

Подача звука: виртуальный микрофон Steam (выбран, ничего не ставим); запасной вариант — VB-Cable
(нужна установка драйвера с правами администратора).

## Устройство

```
Quest (браузер)                          ПК (сервер, Python)
┌──────────────────────────┐   HTTPS    ┌────────────────────────────────────┐
│ оболочка (не перезагр.)  │◄──────────►│ раздача файлов + WebSocket         │
│  ├ VR-сеанс, контроллер  │  курок     │  ├ псевдотерминал: claude          │
│  ├ микрофон → звук ──────┼───────────►│  ├ звук → виртуальный микрофон     │
│  ├ окно терминала ◄──────┼────────────┤  ├ «зажатый пробел» в терминале    │
│  └ загрузчик сцены ◄─────┼────────────┤  └ слежение за файлами сцены       │
│ сцена (подменяется)      │  ошибки ──►│     → logs/scene-status.json       │
└──────────────────────────┘            └────────────────────────────────────┘
```

На ПК два процесса, запускаются одной командой `npm start`:

**Vite** раздаёт страницу по HTTPS (только на адресе домашней сети) и подменяет модуль сцены
через HMR — это штатный механизм, он корректно обновляет и файлы, которые сцена импортирует.
Изменение оболочки вызывает полную перезагрузку страницы; возврат в VR — через событие
`sessiongranted` браузера Quest (не проверено на шлеме, запасной вариант — флаг браузера).

**Мост** (`bridge/`, Python, aiohttp, слушает только 127.0.0.1; страница ходит к нему через Vite):
- Запускает интерактивный `claude` в псевдотерминале (pywinpty) в папке проекта со своим
  идентификатором сессии; при перезапуске моста разговор продолжается (`--resume <id>`).
- Пускает к терминалу только страницу с кодом сопряжения (вводится в шлеме один раз);
  принимает от страницы только звук и клавиши из короткого списка.
- Голос: курок нажат → звук с Quest копится в буфере, микрофон по умолчанию переключается на
  виртуальный, в терминал идёт повтор пробела. Как только на экране терминала появилось
  `listening…` — буфер проигрывается в виртуальный микрофон (начало фразы не теряется).
  Курок отпущен → доигрывается остаток, пробел «отпускается», микрофон по умолчанию возвращается.
- Принимает от страницы результат подмены (успех или ошибка) и пишет в `logs/scene-status.json`.

**Оболочка** (`web/src/`, three.js) — не перезагружается: VR-сеанс, левый контроллер,
микрофон (сырой звук по WebSocket), окно терминала перед пользователем, загрузчик сцены.

**Сцена** (`web/src/scene/main.js`) — то, что Claude правит по голосу. Контракт:
`export function setup(ctx)` возвращает `{ update(dt), dispose() }`, объекты добавляются в
`ctx.root`. При изменении файла оболочка убирает старую сцену и запускает новую. Если новая
падает — возвращается предыдущая, ошибка пишется в лог.

**CLAUDE.md проекта** — описание проекта и раздел «VR-режим», который действует только для
сессии, запущенной мостом: действовать сразу, без обсуждений и планов; отвечать одной-двумя
короткими строками; править сцену, а не оболочку; после правки запускать `npm run scene:check`
и чинить ошибку самому.

## Управление (левый контроллер)

| Кнопка | Действие |
|---|---|
| Курок (держать) | Говорить; при отпускании промпт отправляется |
| X | Enter (отправить короткую фразу, подтвердить) |
| Y | Esc (отменить запись, прервать Claude) |
| Стик вверх/вниз | Стрелки в меню Claude / прокрутка |
| Стик нажать и держать 1 с | Принудительная перезагрузка страницы (запасной выход) |

## Решения исполнителя (не согласованы отдельно, можно поправить)

- Мост на Python (терминал и звук на Windows проверены именно в нём), страница — через Vite.
- Автоотправка при отпускании курка — через настройку `voice.autoSubmit` только для этой сессии
  (флаг `--settings`, проверено). Срабатывает от трёх слов, для коротких фраз есть кнопка X.
- Код сопряжения и привязка только к адресу домашней сети: без них любой в сети (включая
  Radmin VPN) мог бы управлять Claude на этом ПК.
- Микрофон по умолчанию переключается только на время удержания курка.
- Модель и уровень усилий VR-сессии — в `config.json`, по умолчанию быстрый вариант
  (скорость важнее, чем в обычной работе).
- Сертификат HTTPS — самоподписанный, создаётся один раз (браузер помнит разрешение около
  недели, потом предупреждение придётся принять снова).
- Терминал в VR рисуется на холсте-текстуре; если текст окажется мутным — следующий шаг
  WebXR quad layer.

## Одноразовая настройка в шлеме

Открыть адрес в браузере Quest, принять предупреждение о сертификате, ввести код сопряжения,
нажать «Войти в VR» и разрешить микрофон — всё курком левого контроллера.
