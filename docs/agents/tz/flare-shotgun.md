# ТЗ: «Сигнальный дробовик» — выстрел

Пушка: запись `flare_shotgun` в `web/src/scene/generated-guns.js` (уже есть, голограмма). Картинку и 3D
делает другой агент; здесь только выстрел. Делать СТРОГО по приоритетам: следующий шаг — только когда
предыдущий принят (проверка ниже выполнена и выведена в отчёт).

## Выдача по частям (важно: отзывчивость)
Пользователь в VR смотрит на результат СРАЗУ и может поправить дальность, скорость, эффекты, пока
остальное ещё пишется. Поэтому:
- каждый приоритет (и даже его рабочая половина) сразу живёт в игре — сохранил файл, `scene:check` = OK,
  сцена подменилась на лету; ничего не копить «до конца»;
- как только пункт принят — сразу короткое сообщение диспетчеру (`SendMessage` to `main`): «П1 в игре:
  свеча летит и горит; дальность ~X м, скорость Y м/с» — диспетчер скажет пользователю в шлем;
- правки пользователя по ходу (присланные диспетчером) — главнее плана: внести, выдать, продолжить;
- каждое сохранение оставляет пушку рабочей (без полуготовых состояний, ломающих выстрел).

## П1. Дробовик стреляет свечой (обязательно)
- Курок → одна свеча (не пуля), не чаще раза в 0,9 с (`gapMs: 900`, полуавтомат).
- Свеча летит по дуге (гравитация), ~35–45 м/с, видна в полёте: яркая точка + короткий след.
- Падает на землю и лежит там, ГОРИТ: мерцающее пламя + свечение. Цвет пламени случайный на выстрел
  (красный / оранжевый / зелёный / бело-фиолетовый).
- Попала в пса / коптер / мишень — падает рядом и горит. Не упала за 6 с — гаснет в воздухе.
- До 8 свечей одновременно, лишняя вытесняет самую старую.
- **Приёмка П1:** `npm run scene:check` = OK, затем `npm run test:shot -- flare_shotgun --shot` →
  `fired: 1`, `landed: 1` (через ~2–4 с, `landedAfterS`), `landPoint` на земле, `pageErrors: []`;
  код выхода 0. Цвет свечи — `npm run vr:eval -- "__sceneState.projectileDebug.flare.stats().live"`.

## П2. Через 3 с в свечу прилетает снаряд сверху (обязательно)
- Отсчёт 3 с ИГРОВОГО времени от приземления (учитывает «Время ×N»).
- Снаряд падает ВЕРТИКАЛЬНО сверху точно в свечу: виден яркий след с неба (~0,3–0,5 с), затем полный
  артиллерийский разрыв (огонь, дым, воронка, тряска — как у артиллерии).
- Урон по площади ~9 м, сильнее в центре: вражеские псы и коптеры; союзники НЕ ранятся. Убийства и
  ранения засчитываются игроку (крестики, «клац» — kill-confirm).
- Свеча после разрыва исчезает.
- **Приёмка П2:** одна команда `npm run test:shot -- flare_shotgun --enemy 3 --ally 3 --shot` (нужна
  битва псов) → код выхода 0: `strikes: 1` (`strikeAfterS − landedAfterS` ≈ 3,4 с), `checks.enemyHurtAndCredited`
  (пёс ранен/убит, `killConfirm` kills/hits выросли), `checks.allyUnharmed`; снимок разрыва — `screenshot`.

## П3. Звуки (желательно, после П1 и П2)
- Выстрел: глухой «тумп» лаунчера. Свеча: шипение, пока горит (тихое, затухает при погасании).
- Перед ударом: короткий свист падающего снаряда, затем взрыв (можно взять артиллерийские).
- Свои звуки — запечённые буферы через пул голосов (ПРАВИЛА ЗВУКА в recipes.md); не занимать чужие
  голоса так, чтобы глушить ракетницу.
- **Приёмка П3:** `sound.stats()`/статистика модуля: на выстрел создаётся ≤ 1 BufferSource на звук,
  новых узлов графа нет; ошибок нет.
